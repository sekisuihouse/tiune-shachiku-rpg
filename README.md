# 社畜RPG：定時退社の戦い

ブラウザだけで遊べる、オフィスが舞台の2ステージ横スクロールアクションゲームです。初回起動時は壮大なSF映画風の縦スクロール導入から始まります。第1ステージでは職種の異なる上司8人を踏んで撃破し、第2ステージではエナドリの空き缶をラスボスへ投げて、定時退社を勝ち取ってください。

## 実行方法

`index.html` をダブルクリックして、Chrome / Edge / Safari などのブラウザで開いてください。ローカルサーバーや追加インストールは不要です。

## 操作

- 左右矢印キー: 移動
- 上矢印キー: ジャンプ（第1ステージでは落下中に上司の頭を踏むと撃破）
- Z: 回収したエナドリの空き缶を投げる（第2ステージ）。最終連打イベント中は「エナドリを摂取！」ボタンの代わりになる
- R: ゲームオーバーまたはクリア後にリスタート（導入ストーリーは再表示しません）

## 仕様

- 第1ステージには上司8人が配置されています。一番右端の会議室まで進むと、上司を全滅させなくてもラスボスが待つ第2ステージへ移動します。配置間隔を空けているため、同時に画面に現れる上司はおおむね4人以下です。
- 一般: そのまま追跡し、穴や足場から落下します。
- 魔法使い: 紫のローブで、一定距離を保って魔法のマウスを投げます。足場へジャンプし、落下時は持ち場に戻ります。
- 投擲主: オレンジのベストで、一定距離を保ちながら勇者の位置を狙う放物線の書類攻撃を行います。落下時は持ち場に戻ります。
- 動く足場とジャンプ台を配置しています。高い書類棚やフロアの穴を利用して進めます。
- 第1ステージには中身入りのエナドリが床を転がっています。缶は穴の手前で反転して落ちません。飲むとスーパー勇者になり、被弾を1回だけ通常勇者へ戻ることで耐えられます。開始時はスーパー勇者です。
- エナドリを取ると、生成した覚醒演出ビジュアルを背景に全画面で「覚醒！ガンギマリ！」を表示します。
- 覚醒カットインは右から左へ0.5秒で通過し、その間はゲーム内時間が停止します。被弾後の点滅中でも、上から踏めば敵・投擲物を倒せます。
- 飛んでくる魔法・書類・エナドリ吐き出し攻撃は、上から踏みつけると破壊できます。
- ラスボスはジャンプで接近し、エナドリを飲んで吐き出す攻撃を行います。捨てられた空き缶を回収して投げるとダメージを与えられます。
- 空き缶は最大9本までストックでき、`Z` キーで順に投げられます。
- ラスボスのHPを一度ゼロにすると第2形態へ移行します。散弾ゲロの増量、横方向レーザー、子分の召喚が加わり、移動・攻撃頻度も上がります。第2形態への移行時はゲーム内時間を止めてカットインを表示します。
- 子分の攻撃はエナドリ缶のみです。上から踏みつけると倒せて、空き缶を1本入手できます。
- 第1ステージのエナドリを5本すべて飲むと、カフェイン過剰摂取の死亡イベントになります。
- 第2形態を撃破すると最終イベントに入り、プレイヤーは無敵になります。キャンバス上の「エナドリを摂取！」ボタンを100回クリック（または `Z` 連打）するとカフェイン過剰摂取の死亡イベント、ラスボスが飲み始めてから60秒耐えるとラスボスが力尽きてクリアです。
- ラスボスを倒すと `10144.jpg` を背景に「帰宅！快眠！」を表示します。
- BGMは `BGM.mp3` をループ再生します。ブラウザの自動再生制限のため、最初のキー操作で再生が始まります。
- ステージ・当たり判定・重力・ジャンプはすべて `index.html` 内の JavaScript で実装しています。

## 使用画像

ゲームで利用する `hero-normal.png`、`hero-super.png`、`hero-hold.png`、`hero-throw.png`、`general.png`、`wizard.png`、`thrower.png`、`boss.png`、`boss-throw.png`、`boss-phase2.png`、`energy-grid.png` は、人物画像を参考に生成して背景を透過処理したPNGです。`energy-grid.png` には10種類のエナドリが入っており、ゲーム中では個別のピックアップとして利用します。

演出用の画像として、覚醒カットインに `awakening.png`、カフェイン過剰摂取イベントに `caffeine-warning.png`、クリア画面に `10144.jpg` を使用します。
